# Project 2: Exploratory Data Analysis (EDA)

EDA project from Baraa's course (12 lessons) - understand data before reporting.

## Analysis Covered
1. Database exploration: tables, columns, row counts
2. Measures & dimensions: total sales, quantity, customers
3. Date analysis: trends by year/month
4. Category / product / customer / region breakdowns
5. Data quality checks: NULLs, duplicates, outliers

## File
- `eda.sql` - All EDA queries with comments

## Key Learning
GROUP BY, aggregations, date functions, ranking, data profiling.
