# Project 3: Advanced Data Analytics

Advanced analytics project (9 lessons) - answer real business questions.

## Business Questions Solved
- Revenue by category / customer / year
- Running totals & moving averages (window functions)
- Customer segmentation (VIP / Regular / New)
- Year-over-year growth, Top N products
- Cumulative analysis & performance benchmarking

## File
- `analytics.sql` - CTEs + window functions for each task

## Key Learning
CTEs, ROW_NUMBER/RANK, LAG/LEAD, SUM OVER (PARTITION BY), CASE segmentation, business storytelling with SQL.
